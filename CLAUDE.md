# Project Instructions

Use task_plan.md as the source of truth for the current project plan.

Before starting work:
1. Read task_plan.md.
2. Determine the next incomplete task.
3. Work on that task.
4. Update task_plan.md when progress is made.
5. Do not mark a task complete until the implementation is verified.

When implementing code:
- Follow the existing project architecture.
- Run relevant tests.
- Do not modify unrelated files.
